PROMO, HARGA CORET, DAN KUOTA
Buka promo-config.js. Fitur berikut disiapkan tetapi default-nya nonaktif:
- enabled: true mengaktifkan kampanye setelah endsAt diisi waktu akhir yang nyata.
- endsAt: tanggal/jam ISO 8601 dengan zona +07:00. Timer tidak reset ketika
  halaman dimuat ulang, dan blok kampanye disembunyikan setelah berakhir.
- previousPackagePrices: isi HARGA TOTAL SEBELUMNYA yang benar-benar pernah
  berlaku untuk paket sebanding. Format objek berisi array empat angka pada
  key "1on1" dan "grup". Urutan Reguler, Intensif, Persiapan Ujian, Cakap Digital.
  Website menghitung sendiri harga coret per jam. Harga lama harus lebih tinggi.
- quotaEndpoint: URL API kuota dari sistem pendaftaran Anda. API harus
  mengembalikan JSON {"remaining": bilangan bulat >= 0, "updatedAt": waktu ISO}.
  Jika lintas domain, endpoint harus mengizinkan CORS dari situs Anda.
  Kuota diperbarui tiap 30 detik. Data berusia lebih dari 2 menit atau permintaan
  gagal disembunyikan. Website tidak mengurangi kuota sendiri.
  Backend/API kuota belum tersedia dalam paket statis ini: perlu dihubungkan
  ke catatan pendaftaran yang benar. Mengisi angka acak bukan data real-time.
